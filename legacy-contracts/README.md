# Legacy contract editors

This folder preserves the previously uploaded residential and commercial contract editors and original PDF assets for reference. The active full-stack contract generator is now under `server/contracts/` and is wired through the server application. These legacy static files are not the application entry point.

The full-stack application is not deployable as GitHub Pages static hosting because it requires the Node.js server, database, authentication, and storage services. Use the Manus project hosting or another Node-compatible host for the complete platform.
